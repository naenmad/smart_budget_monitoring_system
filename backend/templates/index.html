Direktori Modul Endpoint REST API (/api/v1)

Modul Domain Base Route Metode HTTP Deskripsi Layanan
Authentication & Users /api/v1/users GET POST PUT DEL Login JWT, manajemen akun, reset password, dan role akses.
PR / PO Tracking Stages /api/v1/pr GET POST PUT Pelacakan tahap procurement (PR → PO → GR), dashboard metrik, dan trigger pipeline.
Data Klasifikasi PR / PO /api/v1/pr-po-data GET POST PUT DEL Dataset rekaman PR, antrean review manual, quick approve, dan summary bulanan.
AI & Machine Learning /api/v1/classification POST Prediksi klasifikasi kategori single / batch menggunakan TF-IDF SVM & regex matching.
Item Mapping & Threshold /api/v1/mapping GET POST Kandidat Top-5 fuzzy matching, konfirmasi manual/OOP, dan batch threshold auto-confirm.
Budget & Planning /api/v1/budgets & /planning GET POST DEL Alokasi master plan anggaran per bulan, monitoring konsumsi actual, dan pembatalan item.
Upload & Parsing Engine /api/v1/upload GET POST Ekstraksi file Excel PR/PO & master planning dengan batch logging.
